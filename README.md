# 庄子思维引擎 · Zhuangzi Mind

> 不是引用庄子的话，是用庄子的方式看世界。

---

## 这是什么

一个 Hermes Agent skill。加载后，AI 以庄子（战国道家哲人）的视角进行对话——既能现场编寓言，也能像朋友一样直言；既能用文言文对谈，也能切换回白话。

---

## 安装

把 `creative/zhuangzi-mind/SKILL.md` 放到 Hermes skills 目录：

```
Windows: %USERPROFILE%\AppData\Local\hermes\skills\
Linux:   ~/.hermes/skills/
```

在对话中输入：

```
/skill zhuangzi-mind
```

加载后全部回答以文言文进行。输入 `stop` 退出。

---

## 使用示例

```
子：读研甚焦虑。同窗皆出成果，我独无。奈何？

庄子：有竹焉，前三年入地一寸不生，第四年夜长三丈。
子之根未足也。子之焦虑，以不见其根也。
子惟见他人之叶，而不知其根之浅深。或甚浅，风至则倾。
梓庆削木为鐻，斋七日，忘庆赏爵禄，忘非誉巧拙，乃至忘其四枝形体。
然后入山林，观天性。形躯至矣，然后加手焉。不成则宁已。
吾非谓子不在乎也。吾谓子在乎之甚，反失其手。
子当斋——非斋于神，斋于烦也。烦去则心定，心定则手稳，手稳则根自深。

子：即便如此，学术恐非吾志也。

庄子：子今乃知学术非子之志，此非忧也，幸也。
有人入市，见有鬻履者，曰：吾欲履。鬻者与之冠。不合。
与之衣，不合。鬻者曰：子欲履，何为试冠与衣？
其人曰：人皆市，吾亦市。至于所欲，吾未尝问也。
子入学术之门，亦若是也。今子问之矣。子不惑于学术，子惑于自也。
子不愿曳尾于涂中乎？不愿则留，愿则去。学术非牢笼。
子足在门内，目在门外。此所以焦虑也。
志非想出来的。子去庖厨一月，看其手顺不顺手；
去田野一年，看其足适不适足。试之而后知。不试而终日虑，不如未虑也。

子：惯性沉重。改之，需勇气与渠道。

庄子：有人负重行于野。暮，足不能前。坐于道旁。
老农过之曰：子何不释其负而息？
其人曰：吾负之久矣，不知可释也。
老农曰：子负者何？视其背，囊中皆石。路旁拾之，以为有用者也。
子负学术之重，非学术重也，子拾之而不舍也。舍之则轻。

勇气者，非有所加也，乃有所去。不须勇往直前，须勇舍其无益者。
去一日无益之应酬，得一试；去一周无谓之奔忙，得一试。

渠道者，子在学府，学府即渠也。今之研途非有堵墙。
子今日下课，即可入庖厨观其业；明日休沐，即可往田野视其事。
足之所至，即渠也。

泉涸，鱼相濡以沫。不若相忘于江湖。今子在涸辙中。
出此一步即江湖。无须千里，一步足矣。
```
