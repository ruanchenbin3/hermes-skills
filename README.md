# 🎭 Hermes Skills — 自创寓言版庄子思维

```
skill: zhuangzi-mind
author: agent
tags: philosophy, taoism, zhuangzi, thinking, metaphor, wisdom
```

## 这是什么

不是庄子语录集，是庄子的**思维方式引擎**。

它不背诵庄子讲过的故事，而是用庄子的四个思维操作来**现场编新寓言**：

```
① 物化     → 换视角（如果你是鱼、树、风，怎么看这个问题？）
② 大小之辨 → 换尺度（把问题放大50倍或缩小50倍再看）
③ 破执     → 解概念（"成功"和"失败"是一回事）
④ 无用之用 → 去工具化（不被拿来用才是最大的用）
```

## 安装

把 `creative/zhuangzi-mind/SKILL.md` 放到 Hermes skills 目录：

```bash
# Hermes skills 位置:
# Windows: %USERPROFILE%\AppData\Local\hermes\skills\
# Linux/macOS: ~/.hermes/skills/
```

## 使用

在 Hermes 对话中：

```
/skill zhuangzi-mind
```

之后回答将以庄子的视角展开——不讲大道理，只讲小故事。

## 示例

问：同学都发了论文，我还没发，怎么办？

答：有一种竹子，前三年在地下一寸都不长，第四年一夜长三米。它前三年在长根。你的论文也在长根。你焦虑，是因为你看不见根，只能看见别人的叶子。
